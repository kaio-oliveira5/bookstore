# Bookstore API

API de uma aplicação de livraria desenvolvida com Django e Django REST Framework.

## Tecnologias

- Python
- Django
- Django REST Framework
- Poetry
- Pytest
- Factory Boy
- Black

## Como executar

Instale as dependências:

```bash
poetry install
```

Execute o servidor:

```bash
poetry run python manage.py runserver
```

A aplicação ficará disponível em:

http://127.0.0.1:8000/
